# Public RTX 4060 hardware reports

Only the redacted JSON produced by `hardware-inventory --write-public-report`
belongs here. It contains neither the physical GPU UUID nor another stable GPU
identifier. The raw UUID and timestamped immutable inventory receipt remain
under the ignored `eightgb_bench/local/` directory on the laptop; the public
report binds only the opaque SHA-256 of that local receipt.

One report is hardware proof only. It is not a model admission, a server
authorization, a render receipt, or an 8 GB compatibility claim.
