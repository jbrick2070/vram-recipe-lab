# R4 Driver Judgment

Antigravity completed on `gemini-3.6-flash-low`. After Jeffrey refreshed the
Claude CLI subscription login, Claude Code also completed R4 on Sonnet/high.
This was a four-round campaign with four completed external reviews:
Antigravity R1/R3/R4 and Claude R4. R2 high and its one medium retry timed out
without review files; Claude R1 failed auth. The Codex driver wrote and grounded
all four anchors and judgments.

## Accepted

- CONFIRMED `[P5]`: name the source-delivery helper/interface and receipt
  namespace so the post-process cannot be silently omitted.
- CONFIRMED `[P7]`: state explicitly that all sentinel comparisons use S0 and
  settled sampling occurs on the same persistent verified server.
- CONFIRMED `[P8]`: 90 frames at 24 fps is necessary evidence, but the measured
  container duration still belongs in the receipt and remains the actual
  one-frame tolerance check.
- CONFIRMED verify-at-build items: 8199 ownership/Sage-free boot, fixture hashes,
  Mini Mime prompt/timing, `nvidia-smi`, and final server-receipt cleanup.
- CONFIRMED CLAUDE `[P7]`: sentinels must be warm and identity-continuous; this
  was already a P0 implementation blocker and stays mandatory.
- CONFIRMED CLAUDE `[P5]`: the mux helper/receipt is build-blocking, not a manual
  prose step.
- CONFIRMED CLAUDE `[P8]`: compare ffprobe delivery duration against the recipe's
  declared tolerance with an epsilon safe at exactly 1/24 second.
- CONFIRMED CLAUDE `[P6/P7]`: document ESCALATE as prose evidence and clarify
  bidirectional argv validation without implying two live suite modes.

## Rejected

- MISREAD `[P2/P7]`: replacing the planned nonce/create-time/direct-parent
  authorization with the current PID-only environment variable would preserve
  the confirmed spoof/PID-reuse bug.
- MISREAD `[P7]`: bidirectional pinned-memory validation means live argv must
  match the configured boolean in either mode; it does not mean toggling the
  flag during one suite.
- INCOMPLETE `[P8]`: frame count/fps alone does not prove the muxed container's
  measured endpoint. Retain explicit ffprobe delivered duration.
- MISREAD CLAUDE `[V1]`: R2V uses its own frozen R2V template and should not share
  the I2V template hash.
- MISREAD CLAUDE `[V5]`: the receipt schema field is `fixture`, not
  `fixture_label`; current validator and live references use the correct renamed
  basename.
- REJECTED CLAUDE `[O1]`: the empty UI `workflow` scaffold is canonical across
  these API recipes and harmless; removing it only from Mime would create
  needless generator divergence.

## Convergence

The plan is converged. No additional planning round is warranted. Build is
blocked only by the R4 anchor's six explicit implementation/test items, followed
by final review, live schema validation and the frozen render sequence.
